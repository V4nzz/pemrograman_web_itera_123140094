## 🚀 Cara Menjalankan Proyek Secara Lokal

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/V4nzz/pemrograman_web_itera_123140094.git
   ```

2. **Masuk ke direktori repositori:**
   ```bash
   cd pemrograman_web_itera_123140094
   ```

3. **Buka folder tugas yang diinginkan:**
   - Untuk **Pertemuan 1**: Buka file `ivannandira_123140094_pertemuan1/index.html` di browser Anda atau gunakan ekstensi *Live Server* di VS Code.
   - Untuk **Pertemuan 2**: Buka file `ivannandira_123140094_pertemuan2/index.html` di browser Anda.
